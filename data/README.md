# Data — Paper_GFJ

All input data for this paper is derived from the parent GeopoliticalRisk repository. This directory contains copies (or output of `prepare_data.py`) of the relevant files.

## Source paths (parent repository)

| File here | Source in parent repo | Description |
|-----------|----------------------|-------------|
| `panel_daily.parquet` | Built by SP01 | Unified analysis panel: date × country with returns and shock intensity |
| `shocks_long.csv` | `../results/shocks/paper_rawcov_v1_sp2diff_p0005/events.csv` | Declustered EVT shock events |
| `clusters.csv` | `../data/clusters_input.csv` | Country → cluster mapping |
| `stock_prices.xlsx` | `../data/stock_prices.xlsx` | Raw 19-country daily equity prices (do not copy — reference) |

## Locked vintage

The shock series uses the locked paper-candidate GDELT vintage:
`../data/gdelt_indices/conflict_intensity/20251222_paper_candidate/`

This is the same vintage used in the BIR paper submission.

## Study sample

- **Countries:** 19 European equity markets (Austria, Belgium, Bulgaria, Croatia, Finland, France, Germany, Greece, Hungary, Ireland, Italy, Netherlands, Norway, Poland, Portugal, Romania, Spain, Sweden, United Kingdom)
- **Period:** 2017-01-01 to 2025-10-15
- **Frequency:** Daily (trading days only)
